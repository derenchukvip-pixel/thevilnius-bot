# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

Spring Boot 3.3 / Java 21 app that scrapes the latest article from https://thevilnius.lt/, renders a 1080×1350 feed PNG and a 1080×1920 Story PNG via Playwright, and posts both to Instagram via the official Meta Graph API. Runs on a daily cron (`0 0 10 * * *` — 10:00 server time).

Captions are generated by Anthropic Claude Haiku (`CaptionService`), which also picks the headline's "key phrase" for the yellow highlight in the rendered image.

The Story includes a visual "Подробнее →" CTA pill — note that this is image-only; the Meta Graph API does NOT support attaching clickable link stickers to Stories, so the URL is currently surfaced only visually + via the caption.

## Build & Run

```bash
mvn clean package -DskipTests
mvn spring-boot:run
```

## Install Playwright browsers (one-time)

```bash
mvn exec:java -Dexec.mainClass="com.microsoft.playwright.CLI" -Dexec.args="install chromium"
```

## Configuration (`src/main/resources/application.properties`)

| Property | Description |
|---|---|
| `instagram.user.id` | Instagram Business account ID |
| `instagram.access.token` | Long-lived Graph API token |
| `app.public-url` | Public URL (e.g. ngrok) so Instagram can fetch the image |
| `anthropic.api-key` | Claude API key for caption + key-phrase generation |
| `server.port` | Default 8080 |

## Architecture

```
ScraperService      — Jsoup scrape of thevilnius.lt → ArticleInfo (title, imageUrl, link, content, keyPhrase)
CaptionService      — Claude Haiku: formatCaption() for the post caption; findKeyPhrase() for the highlight
ImageService        — Builds HTML, renders 1080×1350 feed (upload.png) + 1080×1920 Story (story_upload.png) via Playwright
InstagramService    — Two-step Graph API POST per surface: /media → /media_publish (feed + STORIES)
StorageController   — GET /images/{filename} serves storage/ as PNG for Instagram to pull
PostScheduler       — @Scheduled(cron="0 0 10 * * *") daily driver; deduplicates via last line of history.txt
ScrapeTestController — /test/scrape, /test/generate, /test/force-post, /test/force-story for manual triggers
```

### Flow

1. `PostScheduler.run()` fires daily at 10:00 (server timezone).
2. Checks `history.txt` — skips if the latest scraped link matches the last line.
3. `ScraperService` fetches the homepage, selects the first `<article>` element.
4. `CaptionService.findKeyPhrase()` picks the most newsworthy 1–4-word substring of the headline (Claude Haiku).
5. `ImageService` renders the feed PNG (LIGHT/DARK theme alternation via `theme_counter.txt`) and the Story PNG with the same key-phrase highlight + visual "Подробнее" CTA.
6. `CaptionService.formatCaption()` rewrites the article body into a Warsaw-style IG caption with emoji per paragraph.
7. `InstagramService.postImage(caption)` publishes the feed post, then (best-effort) publishes the Story.
8. The article link is appended to `history.txt`.
